# 管理后台

管理员登录后通过账号菜单进入 `/admin/`。所有下载、反馈概览和服务报告接口均要求服务端管理员身份；普通用户不能读取统计。

- 概览：北京时间今日、近 7 天下载发起次数，状态为 new/triaged 的待处理反馈，以及最近软件发布。
- 下载统计：近 7/30/90 天快捷范围、自定义日期、软件筛选、趋势、软件排名、版本次数及占所选范围总下载的比例。CSV 保持每日软件明细格式。统计启用前显示“尚未统计”，启用当天为部分数据。
- 服务检查：每 6 小时由 GitHub Actions 运行；也可在 Actions 页面手动运行。检查所有有独立安装包的软件的最新正式版，实际读取安装包并计算 SHA256、核对已发布文件大小，核对更新源版本、下载地址、大小与签名字段存在。此检查不宣称验证 Sparkle 签名的密码学真实性；已有构建门禁独立验证镜像清单签名。

服务检查每轮失败会立即复测；首次仍失败为“异常待复核”，同一版本与下载地址连续两轮失败为“持续异常”。恢复后清零。超过 12 小时的报告显示过期；当前版本、URL 或 SHA256 与报告不一致时显示尚未检查。缺少哈希、大小或独立安装包明确跳过，不伪造通过。

检查报告 `public/service-health.json` 只包含公开软件元数据、检查时间和结果，不包含用户资料、反馈或私有下载统计。报告提交触发 Cloudflare Pages 发布；工作流只使用仓库自带 GITHUB_TOKEN，不新增 Cloudflare 凭据。最终跳转地址去除查询参数，避免保存临时签名参数。

GitHub 定时任务可能延迟，应以后台显示的最近检查时间为准。服务报告属于检测结果，不会修改安装包、自动更新源或反馈。
