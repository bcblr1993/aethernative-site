# 全站功能与布局验收 · 2026-10-13

本次范围：当前本地工作区的中英文网站、9 款软件页面、版本/文档/动态、反馈和管理后台。验收环境为构建产物 + Cloudflare Pages Functions + 独立本地 D1，使用测试账号；没有修改生产数据或执行部署。

## 已加入的功能

- 反馈最多 3 张截图：选择/拖放、压缩、预览、移除、失败保留；提交者和管理员可查看，其他用户不能访问。
- 管理员登录时显示新反馈提醒和数量，进入新反馈筛选，处理后更新数量。
- 用户管理：搜索、状态筛选、登录来源/时间、反馈数量、查看反馈、强制退出、禁用/恢复。禁用立即撤销网页/App 会话；恢复要求重新登录。管理员账号受保护。
- 软件与 GitHub 仓库一一对应，反馈页、支持页和管理后台提供仓库及 Issues 入口，数据接口也返回对应地址。

## 本轮全站检查后修复

- 全局尊重 `hidden` 状态，避免按钮、头像和管理入口被组件的 display 样式意外显示。
- 修复 320px 英文导航溢出；平板使用折叠菜单，支持点击外部、Escape 和尺寸变化收起。
- 语言切换保留软件查询参数和页内位置。
- 版本说明中的长代码/哈希可以换行；软件标题均衡换行，长软件名与下载按钮不会互相挤压。
- 固定导航提高背景遮挡，滚动时正文不干扰菜单；修正 404 页面边距和统计区多余留白。
- 支持页链接改为紧凑双列，补齐仓库入口后仍能快速浏览多款软件。
- 图集提供播放/暂停，离开视口、隐藏标签页、悬停和键盘交互时正确暂停；支持减少动态效果。
- 剪贴板不可用时选中校验值并提示手动复制。
- 会话 401、跨标签退出和历史缓存恢复时同步登录状态；退出后晚返回的请求不能恢复用户信息。临时网络失败允许重试。
- 统计页面退出/失效后清空表格及 CSV；无效日期不能导出旧报表。
- 反馈分页采用时间与 ID 双字段游标，同一毫秒的反馈不会跨页遗漏；末页不显示多余加载按钮。
